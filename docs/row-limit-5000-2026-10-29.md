# Лимит 5000 позиций — 29.10.2026

По запросу пользователя лимит файла повышен с 1000 до 5000 позиций.
Архитектура и модели не изменены.

- `parser.MAX_ITEMS=5000` применяется ко всем поддерживаемым форматам.
- Предельное смещение страницы результатов берётся из той же константы.
- Массовая отмена решений принимает до 5000 ID.
- Подсказка загрузки и README обновлены.
- Бюджет второго мнения для файлов больше 1000 строк увеличен пропорционально.
  Основное извлечение по-прежнему использует `LLM_BUDGET` из окружения; если
  времени не хватает, оставшиеся строки обрабатываются резервными правилами.

Ограничения 10 МБ, количества ячеек, распакованного размера и страниц PDF,
проверки сигнатур и экранирование выгрузки сохранены. Результаты выдаются
страницами до 200 строк. Лимит списка заданий 1000 относится к числу заданий,
а не к позициям файла, поэтому не менялся.

Проверки: файл на 5000 строк читается полностью, 5001 строка отклоняется;
5000 ID для отмены принимаются, 5001 отклоняется. Backend: 281 тест прошёл,
18 пропущены (в том числе отдельная PostgreSQL для миграций не подключалась).
Ruff и сборка/проверка frontend прошли. Docker-сервисы пересобраны.

5000 строк — поддерживаемый размер файла, не обещание обработки за 300 секунд.
Условие ТЗ по скорости относится к 1000 строкам. Полный живой прогон на 5000
строк в рамках изменения лимита не выполнялся.
