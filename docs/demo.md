# Демонстрация для жюри

Достаточно обычного запуска `docker compose up --build`.
Аккаунт и готовая спецификация создаются автоматически при подготовке базы, до готовности API.
Дополнительные команды не нужны.

Сайт: http://localhost:3000. Логин **admin**, пароль **admin**.
Подтвердите политику и обработку файлов на экране входа.
В разделе недавних спецификаций доступно `Спецификация_1000_строк.xlsx`.
Остальные новые аккаунты остаются пустыми: демо принадлежит только admin.

## Происхождение результата

Это снимок реальной обработки нашего внутреннего набора 29.10.2026:
1000 строк, **991 точное совпадение (99,1%)**, 9 несовпадений.
Исходное задание: `2d7ed0c1-062a-4078-9aee-1b367ab1c766`.
Полное измеренное время через HTTP — **121,086 с**, серверное — **120,65 с**.
YandexGPT `yandexgpt-5.1`, пять настроенных ключей, пачка 20 строк,
эмбеддинги `text-search-query`, лимит 20 запросов эмбеддингов/с.
Каталог был загружен, worker перезапущен перед замером, параллельных заданий не было.

После измерения одну строку меняли вручную при проверке экспорта. В демонстрационном
снимке восстановлено её первоначальное предсказание из сохранённого `original`.
Все 1000 кодов повторно сверены с `dataset/organizers/Спецификация_1000_reference.jsonl`.
Результаты, кандидаты, уверенность и статусы не улучшались ради демонстрации.
Название папки organizers историческое; этот набор считаем внутренним, не независимым эталоном.

Снимок `backend/demo_data/demo-1000.json.gz` содержит исходный Excel, предсказания,
эталонные коды для проверки снимка и исходные времена этапов. Это демонстрационные данные,
а не кеш новых запросов. Импорт не обращается к внешним API.
Время, показанное в сохранённом задании, относится к историческому прогону, а не к импорту.

**Ограничения:** 99,1% на нашем наборе не доказывают ≥85% на новых независимых закупках;
121 секунда — результат одного замера, а не гарантия для любого файла или параллельной нагрузки.
Уверенность алгоритма и статус «авто» не равны точности относительно эталона.

## Поведение импорта

- Создаёт стартовую учётную запись и пример при обычном Docker-запуске (`JURY_DATA=1` по умолчанию).
- Для запуска без стартовых данных задайте `JURY_DATA=0`; уже созданные данные это не удаляет.
- Не меняет политику паролей обычной регистрации.
- Не перезаписывает существующий admin с другим паролем или правами.
- Повторный запуск не дублирует задание и не отменяет внесённые человеком изменения.
- Ручные исправления из демо не переносятся в аккаунты других пользователей.
- Известный пароль `admin` нужно изменить перед публичным размещением.

Код демо и снимок входят в Git и Docker-образ. Два больших файла каталога передаются
отдельным комплектом с `db/`, как описано в README. Демо не устраняет необходимость каталога.
