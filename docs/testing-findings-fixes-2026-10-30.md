- PostgreSQL для миграций создан отдельно от рабочей базы; её данные не изменялись тестами.
- Ruff check прошёл; новые файлы отформатированы.
- Frontend: **4/4 теста**, lint и production build прошли.
- Контрольный поиск без нейросетей: **1000 строк, 0 auto, максимальная уверенность 30,3%, 6,773 с**, внешних запросов нет. Это проверка ограничения уверенности, а не доказательство точности классификации.
- Приложение пересобрано и обновлено в Docker после проверки отсутствия активных заданий. Health: каталог ready, извлечение и эмбеддинги on.

Репозиторий и файлы автоматически не публиковались.
2. **Запуск GitHub CI** подтвердится после отправки изменений в GitHub; сейчас подтверждены локальные проверки, workflow подготовлен.
3. **Запуск на другом компьютере** остаётся неподтверждённым: сборка архива и локальные тесты не заменяют проверку участником команды.

## Передача

Архив: `outputs/ktru-lite-delivery-2026-10-30.zip`.
Сборка: `python scripts/package_delivery.py outputs/ktru-lite-delivery-2026-10-30.zip`.
Внутри — исходники текущей рабочей копии, `db/ktru_catalog.jsonl.gz`,
`db/ktru_vectors_yandex.npz` и `DELIVERY-SHA256SUMS.txt`.
После распаковки скопировать `.env.example` в `.env`, заполнить свои ключи и запустить
`docker compose up --build`. Нужны Docker, интернет для образов/пакетов и API Яндекса;
«каталог в комплекте» не означает полностью автономную установку без интернета.

На этапе исправления находок изменения оставались локальными. Затем пользователь отдельно
поручил сохранить их в новой ветке и отправить в GitHub: `codex/release-prep-2026-10-30`.
