# Tokify: Anthropic-совместимый Messages API

В корневом `.env` заполните:

```dotenv
LLM_PROVIDER=anthropic
ANTHROPIC_BASE_URL=https://tokify.sale
ANTHROPIC_MODEL=gpt-5.6-luna
ANTHROPIC_API_KEY=
```

После `ANTHROPIC_API_KEY=` вставьте ключ Tokify и сохраните файл. `.env` исключён из Git.
Ключи Яндекса и GigaChat для этого шлюза не используются. Точное название профиля
`gpt-5.6-luna` предоставлено пользователем; доступность по ключу проверяется реальным запросом.

Приложение отправляет `POST https://tokify.sale/v1/messages` с `x-api-key` и
`anthropic-version: 2023-06-01`. Адрес с завершающим `/v1` также поддерживается.
Системная инструкция передаётся в поле `system`; пользовательское сообщение содержит JSON
строк спецификации. Текстовые блоки ответа проходят существующую проверку значений по
исходной строке. Обрезанный ответ не принимается за успешный. Неизвестный поставщик,
пустой ключ или модель отключают LLM; приложение использует существующие правила.

Чтобы применить код и настройки к работающему Docker-приложению:

```powershell
docker compose up -d --build --no-deps backend
```

Эта команда пересобирает только backend. Модель bge-m3 и контейнер Ollama не пересоздаются.
После запуска загрузите небольшой синтетический файл и проверьте результаты. Полный
тест 1000 позиций следует выполнять после успешной короткой проверки; стоимость,
скорость и точность нового шлюза пока не измерены.

Параллельность по умолчанию сохраняется. При необходимости `LLM_PARALLEL` переопределяет
её; если переменная отсутствует, используется прежняя `GIGACHAT_PARALLEL`. Повышать
параллельность следует в пределах лимита ключа поставщика.

Чтобы вернуться на GigaChat, установите `LLM_PROVIDER=gigachat`, сохраните прежние
`GIGACHAT_*` и примените настройки той же командой. Старые ключи не удаляются.

`anthropic` здесь означает протокол, а не подтверждение производителя модели. Сайт Tokify
прямо указывает, что API ID — профили шлюза, а фактическая модель определяется маршрутом.
Проверенные страницы:

- https://tokify.sale/ — `/v1/messages`, базовый адрес без `/v1` для Anthropic-клиентов.
- https://tokify.sale/check/ — пояснение о профилях и маршрутизации.
- https://platform.claude.com/docs/en/api/messages/create — формат Messages API.

Архитектура не меняется: существующие extractor → embedder → поиск → уверенность, API,
очередь, база и интерфейс сохранены. Добавлен выбор протокола в `backend/extractor.py`.
