# Подключение YandexGPT / Qwen из Yandex AI Studio (для новичка)

Сверено с документацией Yandex Cloud и AI Studio на 20.10.2026. По одному действию на шаг.

## 1. Аккаунт и оплата

1. Откройте https://console.yandex.cloud и войдите с Яндекс ID.
2. Примите условия. Облако `cloud-…` и каталог `default` в нём создаются сами.
3. Слева выберите **Биллинг** → **Создать аккаунт**.
4. Тип — **Физическое лицо**, привяжите банковскую карту, нажмите **Создать**.
5. Дождитесь статуса аккаунта **ACTIVE** и проверьте, что облако к нему привязано.

**Стартовый грант сейчас не выдаётся.** На странице гранта написано: «Пробный период и стартовый
грант для новых клиентов недоступны». Платите по факту, деньги списываются с карты.

**Сколько стоят 1000 позиций.** Замер команды на Qwen3.6 35B: 68 572 входных и 122 364 выходных
токена. По тарифу 0,20 ₽ за 1000 входных и 0,30 ₽ за 1000 выходных токенов это **≈ 50 ₽**.
YandexGPT Lite стоит 0,20 ₽ за любые 1000 токенов, получается ≈ 38 ₽.

## 2. Каталог и folder_id

1. В консоли сверху выберите каталог `default` (или создайте свой: **Создать каталог**).
2. Откройте каталог. Его ID (`b1g…`, 20 символов) виден рядом с названием, есть кнопка копирования.
   В AI Studio (https://aistudio.yandex.ru) ID копируется по наведению на название каталога сверху.
3. Это значение пойдёт в `YANDEX_FOLDER_ID`.

## 3. Сервисный аккаунт и роль

1. В каталоге откройте **Identity and Access Management** → **Сервисные аккаунты**.
2. Нажмите **Создать сервисный аккаунт**, имя — например `ktru-llm`.
3. В поле ролей добавьте **`ai.languageModels.user`**. Больше прав ему не нужно.
4. Нажмите **Создать**.

## 4. API-ключ

1. Откройте созданный сервисный аккаунт.
2. Нажмите **Создать новый ключ** → **Создать API-ключ**.
3. В поле **Область действия** выберите `yc.ai.foundationModels.execute`.
4. **Срок действия** можно не задавать. Нажмите **Создать**.
5. Сразу скопируйте **секретный ключ**: после закрытия окна его больше не покажут.

**Почему API-ключ, а не IAM-токен.** IAM-токен живёт до 12 часов: backend пришлось бы обновлять его сам
и хранить для этого ещё один секрет. API-ключ действует, пока его не отзовут, и подходит только
для вызова моделей. Если он утечёт, украсть можно только доступ к моделям. Отзывается ключ
одной кнопкой.

## 5. Какая модель

| Модель | modelUri | Цена, ₽ за 1000 токенов (вход / выход) | Для нас |
|---|---|---|---|
| **Qwen3.6 35B** | `gpt://<folder_id>/qwen3.6-35b-a3b` | 0,20 / 0,30 | **выбор по умолчанию.** Замер команды: 1000 из 1000 строк за 139 с при 4 потоках, поля 94,9 % (у GigaChat-3-Ultra 89,7 %) |
| YandexGPT Lite 5 | `gpt://<folder_id>/yandexgpt-5-lite` | 0,20 / 0,20 | **не берите:** объявлена устаревшей, отключат 15.11.2026 |
| YandexGPT Pro 5.1 | `gpt://<folder_id>/yandexgpt-5.1` | 0,80 / 0,80 | дороже в 3–4 раза, на нашей задаче не замерялась |

Для Qwen backend сам отключает рассуждения (`reasoning_effort: none`), иначе ответ медленнее.

## 6. Квоты на одновременные запросы

- По умолчанию: **2 одновременные синхронные генерации** без подписки (квота организации/облака).
  Квота привязана к облаку, а не к ключу. **Второй ключ того же облака параллельности не добавит.**
- Где смотреть: консоль → выберите облако → слева **Квоты** → найдите в поиске «AI Studio» или
  «генерац». Смотрите строку про одновременные генерации.
- Как увеличить: отметьте квоту → **Изменить** → введите, например, `8` → **Отправить**.
  Статус запроса — на вкладке **История запросов**. Если кнопки нет, напишите в поддержку
  (https://center.yandex.cloud/support), какую квоту и до скольки поднять.
  Для запроса нужна роль `quota-manager.requestOperator`; у владельца облака она есть.

## 7. Строки в `.env`

Значения впишите сами. `.env` в git не попадает.

```dotenv
LLM_PROVIDERS=gigachat,yandex
YANDEX_API_KEY=
YANDEX_FOLDER_ID=
YANDEX_MODEL=qwen3.6-35b-a3b
YANDEX_PARALLEL=2
```

`YANDEX_BASE_URL` по умолчанию равен `https://ai.api.cloud.yandex.net/v1`, его можно не писать.
`YANDEX_PARALLEL` поднимайте только вместе с квотой из шага 6.

## 8. Проверка одной командой

После `docker compose up -d backend`:

```bash
docker compose exec backend python check_llm.py yandex
```

Ответ `yandex: OK …` значит, что ключ, каталог и модель работают. `401` — неверный ключ;
`403` — у сервисного аккаунта нет роли `ai.languageModels.user`; `404` — опечатка в folder_id
или в имени модели; `429` — превышена квота одновременных запросов.
