# ЕИС Классификатор — кейс № 5

Загрузка XLSX/CSV/PDF → извлечение атрибутов → подбор КТРУ → проверка человеком → CSV/XLSX.

**Стек:** React, FastAPI, Celery + Redis, PostgreSQL + pgvector, Yandex AI Studio.
Векторные кандидаты ищутся точным SQL-поиском; существующие правила сравнения характеристик сохранены.

## Запуск

Нужны Docker Compose и файлы каталога, предоставляемые отдельно:
- `db/ktru_catalog.jsonl.gz` — каталог;
- `db/ktru_vectors_yandex.npz` — соответствующие ему Yandex-векторы размерности 256.

Скопируйте `.env.example` в `.env`, заполните ключи Yandex AI Studio и Folder ID.
Для эмбеддингов используются отдельные `YANDEX_EMBED_API_KEY` и `YANDEX_EMBED_FOLDER_ID`.
Настройки ключей и моделей хранятся только в `.env`.
Подготовка и проверка обоих файлов: [каталог и векторы](docs/catalog-preparation.md).

```sh
docker compose up --build
```

Откройте http://localhost:3000 и зарегистрируйтесь. API: http://localhost:8000/api/docs.
Нажмите на свой логин в шапке, чтобы открыть профиль и изменить логин или пароль.
Для сохранения нужен текущий пароль; другие сеансы после изменения завершаются.
У каждой учётной записи свои спецификации и запомненные исправления. Старые
общие задания без владельца сохранены в базе, но пользователям не показываются.
При регистрации отдельно подтверждается обработка учётной записи, перед загрузкой —
обработка файлов. Использование обезличенных данных для улучшения сервиса необязательно;
согласия можно отозвать в профиле. Политика доступна без входа на `/privacy`.
Первый запуск импортирует векторы в PostgreSQL; дождитесь готовности каталога.
Без рабочих ключей нейросетей режим правил доступен, но результаты полной приёмки не гарантируются.

**Обновление старой установки:** сначала выполните [инструкцию переноса базы](docs/case5-migration.md).
Новый том `pgvector_data` не подхватывает содержимое старого `pgdata` автоматически.

## Приёмка одной командой

```sh
python scripts/acceptance.py --live
```

Нужен Python 3 без дополнительных пакетов. Команда использует Docker и сохраняет
`outputs/acceptance/report.json`. Проверяет PDF на 51 странице, CSV/XLSX, название/бренд/модель,
1000 позиций, точность, время, ручную правку и выгрузку. **--live расходует токены настроенных моделей.**
Наборы организаторов должны присутствовать в `dataset/organizers/`.
Без Python можно вызвать `docker compose --profile acceptance run --rm -T acceptance --live` — отчёт выводится в JSON.

## API и работа

Получите cookie через `POST /api/auth/login` (JSON: login/password).
Загрузите файл multipart-полем `file` в `POST /api/jobs`: ответ 202 содержит job_id.
Читайте прогресс через `GET /api/jobs/{job_id}`, строки — `GET /api/jobs/{job_id}/items`.
Правка кода: `PATCH /api/items/{id}` с JSON `{"ktru_code":"..."}`.
Выгрузка: `GET /api/jobs/{job_id}/export?format=xlsx`. Все схемы и примеры — в Swagger.
