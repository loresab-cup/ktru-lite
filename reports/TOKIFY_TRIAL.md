# Проверка Tokify

Обновление: полный тест 1000 позиций завершён. См. `TOKIFY_FULL_STACK_1000.md`:
253,767 с, 20 строк LLM, 980 строк правил; лимит 200 секунд не достигнут.
Ниже сохранены результаты предыдущего короткого теста.

17 октября 2026 года. Backend запущен с `LLM_PROVIDER=anthropic`, адресом
`https://tokify.sale` и API ID `gpt-5.6-luna`, предоставленными пользователем.
Применён Messages API: `/v1/messages`, отдельный `system`, `x-api-key`.
Ключ принят, все три запроса вернули HTTP 200 и `stop_reason=end_turn`.

## Результат

Тот же небольшой синтетический набор: 7 файлов, 13 товаров, 16 уникальных текстов,
39 полей (название, бренд и модель). Производственный промпт и проверка значений
по исходному тексту сохранены. Обращения последовательные, параллельность 1.

| Вариант | Извлечение набора | Верных полей |
|---|---:|---:|
| GigaChat-3-Ultra, ранее | 10,375 с | 35/39 |
| Qwen3:1.7b локально, ранее | 99,130 с | 28/39 |
| Qwen3.6 35B через Яндекс, ранее | 3,625 с | 37/39 |
| Tokify / gpt-5.6-luna | 107,145 с | 39/39 |

Все 16 текстов обработаны моделью, без подстановки правил. Первый отдельный пробный
запрос занял 38,757 с и не включён в 107,145 с. Затем пакеты по 10 и 6 текстов
заняли 64,500 и 42,644 с. Малый набор не является представительным эталоном:
100% здесь не подтверждают точность характеристик и КТРУ на реальных спецификациях.

Расход за три запроса, включая пробный: 1915 входных и 4134 выходных токена
по данным шлюза. Для основного набора: 1437 входных и 3666 выходных.
Денежная стоимость и остаток пакета не проверялись.

## Вывод

Подключение работает, поля малого набора извлечены правильно. По скорости этот прогон
примерно в 29,6 раза медленнее предыдущего прогона через Яндекс. При текущих настройках
это не подтверждает преимущество для обработки больших спецификаций. Прогон на
1000 строк, поиск КТРУ и измерение от загрузки файла до готового результата не выполнялись.
Лимит 200 секунд не подтверждён.

Новый поставщик остаётся выбранным в `.env` и запущенном backend по запросу пользователя.
Архитектура и формат данных приложения сохранены. Перед подключением прошли 84 теста
backend; после запуска контейнер здоров, каталог готов, 81 509 кодов, состояние LLM — on.

`anthropic` означает формат протокола. По [описанию Tokify](https://tokify.sale/),
названия моделей являются профилями шлюза и не гарантируют использование одноимённых
оригинальных моделей. Фактическая внутренняя модель этим тестом не проверена.
