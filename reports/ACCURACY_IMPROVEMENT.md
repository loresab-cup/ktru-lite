# Улучшение точности подбора КТРУ

Архитектура, схема БД и провайдер Яндекса сохранены. Обновлены существующие поиск, проверка автоматического принятия и передача исходного наименования из API.

## Что изменено

- К векторным кандидатам добавлен поиск по исходному наименованию и вариантам терминов. Сохраняются представители разных названий: многочисленные медицинские картриджи не вытесняют картридж для печати.
- Добавлены проверки типа товара, явно указанного материала и назначения. Например, скобы не назначаются степлеру, деревянный шкаф — металлическому, упаковочный текстильный пакет — мешку для мусора.
- Если подтверждённой категории нет, код не назначается; строка остаётся на ручную проверку.
- Неподтверждённое детское или офтальмологическое назначение, общие шаблоны и спорные фиксированные характеристики блокируют автоматическое принятие.
- Бонусы нового ранжирования отделены от старого расчёта уверенности. Сам процент уверенности ещё не откалиброван как вероятность правильного полного кода.

## Что ещё проверять

- Тонометры: каталог предлагает офтальмологический подтип; назначение источником не подтверждено, auto заблокирован.
- Кабели: остаются варианты напряжения, которых нельзя подтвердить без дополнительных характеристик.
- Перчатки: стерильность не всегда указана; шприцы и папки также требуют проверки конкретного подтипа.
- 75 строк (бинт марлевый, перекись водорода и антисептик) остались без кода после проверки категории/материала. Это не утверждение, что подходящего кода вообще нет: текущий поиск его надёжно не подтвердил.

Измеренные 24.71 с — повторный поиск с уже вычисленными векторами. Этот показатель нельзя сравнивать с требованием полного нового прогона за 200 секунд. Полный новый платный прогон не запускался.

Терминология кабеля ВВГ проверена по [каталогу производителя «Камкабель»](https://kamkabel.ru/catalog/categories/silovye/pvh_do3kv/vvgng-28-a-29--2d-ls_pvh_do3kv/); код КТРУ этим источником не подтверждается.
