# Проверка Yandex AI Studio

Реальные запросы выполнены: результаты короткого теста, извлечения 1000 строк и отдельного поиска сохранены в `YANDEX_TRIAL.md`. Эта инструкция описывает настройку доступа и повторный запуск. Основная конфигурация приложения и архитектура не изменены.

## Доступ

1. Войдите в https://aistudio.yandex.cloud/ с Яндекс ID. При первом входе создайте организацию, облако и каталог по подсказкам сервиса.
2. Привяжите платёжный аккаунт. Этот API платный; наличие и условия стартового гранта проверяйте в своём кабинете. Подписка на чат Алисы для теста API не требуется.
3. В правом верхнем углу AI Studio нажмите «Создать API-ключ», задайте срок действия и нажмите «Создать». Сохраните секретное значение ключа.
4. Скопируйте ID каталога: в интерфейсе AI Studio наведите указатель на название каталога вверху и нажмите значок копирования. ID API-ключа и ID каталога — разные значения.
5. Заполните `yandex-credentials.json.local` в корне проекта. Поле `YANDEX_API_KEY` — секретное значение, поле `YANDEX_FOLDER_ID` — ID каталога. Файл исключён из Git существующим правилом `*.local`. Не отправляйте ключ в чат.

## Тест

Подготовлен `scripts/try_yandex.py`. Использует существующие зависимости backend, отправляет только синтетические данные и не обращается к GigaChat. Сравнение такое же, как в предыдущих прогонах: 13 товаров, 16 уникальных строк, 39 полей. Отдельно учитываются первый пробный запрос и время набора. Сохраняет ответы, расход токенов и ошибки; ошибки API не выдаются за успешный замер.

По умолчанию выбрана облачная `qwen3.6-35b-a3b`: Яндекс рекомендует её для сценариев, где важна скорость. Для сравнения именно с YandexGPT Lite передайте `--model yandexgpt-5-lite`. Lite объявлена устаревшей, отключение запланировано на 15 ноября 2026 года. Облачная Qwen — другая модель, её результаты нельзя выводить из теста локальной Qwen3:1.7b.

Из корня проекта, используя Python с установленными зависимостями backend:

```powershell
python scripts/try_yandex.py --credentials yandex-credentials.json.local --input reports/qwen-fixture-input.json --output reports/yandex-fixture-trial.json
```

В этой рабочей среде подходящий Python находится в `C:\Users\user\Documents\ChatGPT\Женя 2\ktru-lite\.venv\Scripts\python.exe`.

Это только извлечение атрибутов на малом наборе. Полный прогон 1000 позиций, точность КТРУ и лимит 200 секунд требуют отдельной проверки после успешного короткого теста.
