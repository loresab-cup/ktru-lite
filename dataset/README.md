# Датасет для организаторов

Для загрузки в приложение выбирайте файлы **без КТРУ**. Файлы с КТРУ и
эталоны с окончанием _reference.jsonl содержат ответы для сопоставления результатов.

## Основные примеры

| Файл | Назначение |
| --- | --- |
| [1000 позиций без КТРУ](organizers/Спецификация_1000_без_КТРУ.xlsx) | Основная массовая спецификация |
| [1000 позиций с КТРУ](organizers/Спецификация_1000_с_КТРУ.xlsx) | Ответы к основной спецификации |
| [292 позиции без КТРУ](organizers/Спецификация_292_без_КТРУ.xlsx) | Дополнительный файл организаторов |
| [292 позиции с КТРУ](organizers/Спецификация_292_с_КТРУ.xlsx) | Ответы к дополнительному файлу |
| [765 товаров без КТРУ](organizers/Товары_765_без_КТРУ.xlsx) | Входные данные без эталона |
| [Спецификация продуктов без КТРУ](real_produkty/produkty_без_КТРУ.xlsx) | Небольшой пример на 12 позиций |
| [37 позиций в форме ЕИС без КТРУ](eis/ЕИС_37_без_КТРУ.xlsx) | Характеристики на нескольких строках, единицы и диапазоны |
| [Встроенный пример сайта](../frontend/public/primer.xlsx) | Короткое знакомство с приложением |

## Дополнительные наборы

| Папка | Содержимое |
| --- | --- |
| organizers/ | Спецификации организаторов и эталонные коды |
| real_produkty/ | Реальная спецификация продуктов и ответы |
| eis/ | Формы ЕИС, версии с кодами и без них, эталоны |
| modified/ | Изменённые формулировки, единицы измерения и диапазоны |
| human_2026_10_28/ | Описания с сокращениями, опечатками и неполными данными |
| attributes_2026_10_29/ | Строки и разметка для извлечения атрибутов |
| primer/ | Ответы к встроенному примеру сайта |
| synthetic/ | Синтетические строки, длинные описания и некорректные входные данные |

Эталон может содержать несколько допустимых кодов (also_ok) или отметку, что
описания недостаточно для однозначного ответа (label_status). При сравнении
учитывайте характеристики, единицы и полноту исходной строки.
