# Тестовые наборы

Все файлы для проверки подбора кодов КТРУ. Здесь лежат копии, исходники остались на своих местах.
Пары «с_КТРУ / без_КТРУ» содержат одни и те же строки: файл без кодов загружается на сайт
(или отдаётся нейросети), файл с кодами служит ответом.

| Набор | 20.10.2026 | 22.10.2026 | 27.10.2026, нейросети | 27.10.2026, без ключей |

| 1000 изменённые | — | 93,7 % | 95,6 % | 92,6 % |
| 292 строки, точный код | 98,3 % | 97,3–97,9 % | 98,6 % | 95,2 % |
| 292 изменённые | — | 97,3 % | 98,6 % | 93,2 % |
| пример ЕИС и его изменённая копия | 1 из 3 / 2 из 3 | 3 из 3 / 3 из 3 | 3 из 3 / 3 из 3 | 3 из 3 / 3 из 3 |

Зона high (коды, которые ставятся автоматически) 27.10.2026: на 1000 строках верны 98,7 % с
нейросетями и 98,8 % без ключей (неверных кодов в авто 11 и 10; до пересчёта уверенности было
41 и 37), на 292 строках и их копии 100 %. Время 1000 строк: 93–105 с с нейросетями, 22 с без
ключей.

Эталоны и изменённые копии строятся заново одной командой из корня репозитория:

```bash
python scripts/make_dataset.py
```

Смысл изменённых копий тот же, что у исходных: значения пересчитаны точно, диапазон «не менее N»
содержит исходное N. Поэтому правильный код у строки прежний, а сравнение «по смыслу»
(`scripts/evaluate.py`) должно засчитывать и новые формулировки.

Организаторы предлагают делать тестовые примеры так: взять «Описание объекта закупки» из ЕИС,
убрать коды КТРУ и немного изменить характеристики. Точность считается по смыслу: наименование
товара, единица измерения, характеристики и их значения (2000 мм = 2 м, диапазоны учитываются).
