(или отдаётся нейросети), файл с кодами служит ответом.

Время 1000 строк 189–204 с вместе со вторым мнением. Финал, векторы Яндекса (Ollama и bge-m3 в

Эталоны и изменённые копии строятся заново одной командой из корня репозитория:

```bash
python scripts/make_dataset.py
```

Смысл изменённых копий тот же, что у исходных: значения пересчитаны точно, диапазон «не менее N»
содержит исходное N. Поэтому правильный код у строки прежний, а сравнение «по смыслу»
(`scripts/evaluate.py`) должно засчитывать и новые формулировки.

Организаторы предлагают делать тестовые примеры так: взять «Описание объекта закупки» из ЕИС,
убрать коды КТРУ и немного изменить характеристики. Точность считается по смыслу: наименование
товара, единица измерения, характеристики и их значения (2000 мм = 2 м, диапазоны учитываются).
