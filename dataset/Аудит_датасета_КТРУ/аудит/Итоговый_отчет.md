Дата проверки: 18.10.2026. Источник истины — официальная выгрузка ЕИС nsiKTRUNew (дамп `ktru_catalog.jsonl.gz`, релиз catalog-2026-10-16, SHA-256 `eba3fc1009ce002f0bd38f516e0c50b53bb5f20b1b6af97edb3ce87a5081b8d1` — совпадает). Результаты «Проверено по официальной выгрузке ЕИС nsiKTRUNew» означают именно сверку с выгрузкой: карточки на zakupki.gov.ru не открывались (ошибка TLS `SEC_E_UNTRUSTED_ROOT`, проверку сертификата не отключали), поэтому для всех строк в части сайта стоит «Не удалось проверить», ссылки на карточки не указаны. Подтверждения специалистом нет. Лист «Проверка и источники» и папка `исходники_проверки` как доказательство не использовались: каждая строка разобрана заново по дампу.

## 1. Согласованность файлов

- Строк: датасет с КТРУ — 300, без КТРУ — 300, образец — 12. ID уникальны, порядок и содержимое (наименование, характеристики, единица) совпадают полностью, лишних и потерянных строк нет.
- 11 позиций образца сохранены по смыслу (отличия только в пробелах и переносах строк). 012 вынесена составителем отдельно — аудит это подтверждает.
- В образце нет единиц измерения: единицы для 001–011 добавлены составителем по карточке того кода, который потом проверяется. Для 004–007 (молоко, йогурт, ряженка, кефир) выбор кода держится именно на этой единице.

- Коды с пятизначным окончанием (009 `10.81.12.110-00007`, 291 `86.21.10.120-00016`) — настоящий формат ЕИС, не опечатка.

## 4. Пригодность для оценки

- Точных дублей нет. Одна пара с одинаковым наименованием и кодом — 001/002 из образца (тушка и грудка), обе в рабочей части. Искусственных повторов и противоречивых описаний нет.
- Деление: 001–011 — в рабочей части. Пересечений между частями: по кодам 0, по одинаковым товарам 0, по переформулированным дублям 0, по группам похожих товаров 0. Семейства соседних кодов (маски, бинты, перчатки, халаты, мячи и т. п.) целиком лежат в одной части. В разных частях есть смежные, но разные товары (например, 179/180 стеллаж офисный и складской, 294/295 холодное и горячее водоснабжение) — это допустимо.
- Описание дословно повторяет название карточки: 23 из 298 (7,7 %). Из них в 20 строках наименование совпадает с названием карточки (включая все 11 из образца), в 3 строках (293, 294, 297) с названием карточки совпадают характеристики. Ещё 6 строк (046, 053, 060, 253, 255, 296) почти дословно повторяют характеристики карточки.
- Код отличается от соседнего только единицей измерения: 37 из 298 (12,4 %): 20 строк в рабочей части, 17 в контрольной. Для этих строк единица — решающий признак.
- Преобладания нет: крупнейшие рубрики — «Медицинские изделия» (50), «Продукты питания» (48), «Бумага и канцелярские товары» (22). Максимальный повтор кода — 2.
